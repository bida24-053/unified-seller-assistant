Project title and purpose

Unified Seller CRM and Pricing Assistant is a university research and innovation project. It is intended to help informal online sellers and small businesses in Botswana manage customer records, understand purchasing behaviour, notice inactivity risk, and consider evidence-based pricing decisions.

This application is a student research prototype. It is not an existing commercial product and does not use another company's branding.

The problem being addressed

Small online sellers often keep customer and sales information in fragmented chats, spreadsheets or memory. That makes it difficult to see who is still active, which customers are valuable, who may be drifting away, and whether a selling price is defensible. The project explores a single interface that combines CRM, RFM segmentation, churn-risk views and advisory pricing.

Target users

Informal online sellers and small businesses in Botswana who need a practical, understandable view of customers and prices, without requiring a large enterprise system.

Main system components

  • Customer Relationship Management (CRM) directory and customer detail views
  • Recency, Frequency and Monetary value (RFM) segmentation
  • Machine-learning-based customer churn prediction (planned)
  • Explainable pricing recommendations (planned)
  • An integrated business dashboard

Proposed technologies

  • Python and Flask for the web application
  • HTML5, CSS3, JavaScript and Bootstrap 5 for the interface
  • Chart.js for interactive charts
  • SQL database with SQLAlchemy (planned)
  • Scikit-learn for logistic regression, decision trees and regression models (planned)

Development status

Completed in this prototype

  • Six Flask pages with named routes and shared navigation
  • Responsive layout with a persistent desktop sidebar and collapsible mobile menu
  • Demonstration dashboard metrics, filters, tables and charts
  • In-memory customer search, filtering, validation and add-customer form
  • RFM, churn and pricing screens structured for later model integration

Not yet implemented

  • SQL database persistence (current customer additions exist only in memory: {{ customer_count }} records in this process)
  • Data validation and cleaning pipelines for a real dataset
  • Calculated RFM scores from live transactions
  • Trained churn classifiers and genuine performance metrics
  • Trained pricing regression models

Limitations of the current prototype

  • All customers, transactions, prices and charts are synthetic demonstration data.
  • No confidential or real customer information is stored in this repository.
  • Churn-risk labels are not predicted probabilities.
  • Pricing output is an explicit demonstration heuristic, not a trained model.
  • Restarting the Flask server resets any customers added through the form.
